# Auditoría funcional de AulaGuard v0.5.5 — 13 de octubre de 2026

**Revisión:** estática del código `main` en commit `5f2c62261826c3509fd1d6812e2778ae3ed39d98`, contrastada con documentación oficial Microsoft. **No se han ejecutado restricciones en equipos Windows 10/11 de usuarios finales.**

**Conclusión:** NO APTO para distribución en aulas de producción; no es suficiente pasar CI o comprobar que las claves del Registro fueron creadas.

## Confirmaciones Microsoft

- AppLocker es aplicable a Windows 10 2004+ actualizado y Windows 11, incluso Pro (KB5024351). No confundir compatibilidad con correcta configuración de reglas: https://learn.microsoft.com/en-us/windows/security/application-security/application-control/app-control-for-business/applocker/requirements-to-use-applocker
- Colecciones AppLocker: si una colección no tiene reglas, sus archivos se permiten; incluye ejecutables y aplicaciones empaquetadas: https://learn.microsoft.com/en-us/windows/security/application-security/application-control/app-control-for-business/applocker/working-with-applocker-rules
- Políticas distintas para fijar el fondo y para evitar modificarlo: https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-desktop y https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-controlpaneldisplay
- Denegación de acceso a discos extraíbles bajo directiva por usuario: https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-removablestorage

## Condiciones para liberar AulaGuard

1. No distribuir actualizaciones en aulas productivas hasta garantizar reversibilidad: P0 AG-01 y AG-02.
2. Corregir P0 AG-03 y exigir pruebas de aplicación real en sesión estándar separada del administrador.
3. Agregar pruebas de regresión con estado Enforce activo, uninstall, restart, Appx/Win32, wallpaper por menú contextual, Chrome/Edge, dispositivos y perfil nuevo.
4. Proteger archivos y ACL con backups de estado propietario. No sobrescribir configuraciones de dominio o terceros.
5. No publicar un ejecutable estable sin firma Authenticode, Microsoft Defender activo y pruebas Windows 10/11 con informes.
6. El diagnóstico `tests/audit/ReadOnly-ProtectionAudit.ps1` revisa configuración, hives cargados, grupos, AppLocker efectivo y tareas **sin aplicar ni retirar restricciones**. Un reporte parcial no acredita funcionamiento real.

**Nota:** la gravedad refleja posible impacto y cobertura incompleta hallados por revisión estática; para atribuir el fallo exacto en un equipo es necesario inspeccionar su sesión estándar, configuración, políticas efectivas y eventos, sin compartir datos personales.
